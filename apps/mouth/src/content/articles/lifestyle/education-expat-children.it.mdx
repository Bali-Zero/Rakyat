## Costi scolastici

### Fasce di rette annuali

| Tipo di scuola             | Costo annuale     |
| -------------------------- | ----------------- |
| Internazionale (premium)   | USD 20,000-35,000 |
| Internazionale (fascia media) | USD 10,000-20,000 |
| National Plus              | USD 3,000-10,000  |
| Privata indonesiana        | USD 500-3,000     |

## Considerazioni importanti

### Requisiti per il visto

<InfoCard variant="warning" title="Legal Status">
I bambini devono avere un regolare status di visto per frequentare la scuola:

**Obbligatorio:**

- Dependent KITAS (legato al permesso di lavoro del genitore)
- Student KITAS (per motivi di studio)
- Second Home Visa (figli inclusi)

**VOA/Visa-Free:** Generalmente non sufficiente per l'iscrizione scolastica

Verifica i requisiti per il visto prima dell'iscrizione!

</InfoCard>

### Supporto linguistico

| Servizio                              | Disponibilità                        |
| ------------------------------------- | ------------------------------------ |
| EAL (English Additional Language)     | La maggior parte delle scuole internazionali |
| Lezioni di indonesiano                | Tutte le scuole                      |
| Bahasa per principianti               | Molte offrono corsi intensivi        |
| Programmi di lingua madre             | Limitati (alcuni per le lingue principali) |

## Consigli per la scelta

<InfoCard variant="tip" title="What to Consider">
**Oltre gli aspetti accademici:**

1. **Posizione** - Il tempo di percorrenza è importante
2. **Comunità** - Livello di coinvolgimento delle famiglie
3. **Strutture** - Sport, arte, tecnologia
4. **Dimensioni delle classi** - Rapporto insegnanti-studenti
5. **Dopscuola** - Attività disponibili
6. **Lingue** - Indonesiano, lingua madre
7. **Supporto** - Difficoltà di apprendimento, counseling
8. **Futuro** - Preparazione universitaria

Visita più scuole prima di decidere!

</InfoCard>

## Opzione homeschooling

### È legale?

<InfoCard variant="note" title="Homeschooling in Indonesia">
L'homeschooling è **legale** in Indonesia con regolare registrazione.

**Requisiti:**

- Registrazione presso l'ufficio scolastico locale
- Seguire un curriculum approvato
- Verifiche regolari
- Documentazione aggiornata

Molte famiglie expat combinano l'homeschooling con attività locali e tutor.

</InfoCard>

### Approcci più diffusi

| Approccio              | Descrizione                  |
| ---------------------- | ---------------------------- |
| Scuole online          | Strutturate, accreditate     |
| Pacchetti curriculari  | Autogestiti                  |
| Ibrido                 | Scuola part-time + casa      |
| Unschooling            | Apprendimento guidato dal bambino |
