# Galateo culturale indonesiano 2026: guida per expat

L'Indonesia ha ricche tradizioni culturali. Comprendere le usanze locali ti aiuterà a costruire relazioni migliori ed evitare incomprensioni.

## Valori culturali fondamentali

<InfoCard variant="note" title="Key Values">
**La società indonesiana valorizza:**

- **Armonia** - Evitare i conflitti, mantenere la pace
- **Rispetto** - Per gli anziani, la gerarchia, la religione
- **Comunità** - Il gruppo prima dell'individuo
- **Faccia** - Preservare la dignità, evitare imbarazzi
- **Pazienza** - Il "rubber time" esiste davvero
- **Ospitalità** - Accoglienza verso gli ospiti

Comprendere questi valori spiega molte usanze.

</InfoCard>

## Galateo sociale

### Saluti

| Situazione         | Saluto appropriato              |
| ----------------- | ------------------------------- |
| Formale/Lavoro    | Leggero inchino, stretta di mano |
| Informale         | Sorriso, saluto con la mano, "Halo" |
| Anziani           | Leggero inchino, tono rispettoso |
| Musulmani osservanti | Preferita stretta di mano tra stesso sesso |
| Balinesi          | "Om Swastiastu" (saluto)        |

### Contatto fisico

| Comportamento            | Accettabilità             |
| -------------------- | ------------------------- |
| Stretta di mano      | Normale (stesso sesso)    |
| Pacca sulla spalla   | Tra amici                 |
| Toccare la testa     | Mai (sacro)               |
| Indicare con il dito | Evitare (usare invece il pollice) |
| Mano sinistra per dare | Evitare (usare la mano destra) |
| Affetto in pubblico  | Mantenerlo al minimo      |

<InfoCard variant="warning" title="The Head">
**La testa è sacra** nella cultura indonesiana.

- Non toccare mai la testa di qualcuno
- Vale anche per bambini e amici
- Anche le pacche scherzose sono irrispettose
- I servizi di acconciatura sono un'eccezione (contesto professionale)
</InfoCard>

### Scambio di biglietti da visita

| Fase             | Come                                |
| -------------- | ----------------------------------- |
| Quando si offre | Usare entrambe le mani              |
| Quando si riceve | Usare entrambe le mani             |

| Durante la riunione | Tenere visibile sul tavolo      |

### Relazioni d'affari

<InfoCard variant="tip" title="Relationship First">
**In Indonesia:**

- Gli affari spesso seguono la relazione
- Conversazione informale prima degli affari
- Incontri a pranzo/cena importanti
- Costruire fiducia richiede tempo
- Le relazioni personali contano

Non avere fretta di fare affari - investi prima nelle relazioni.

</InfoCard>

## Sensibilità religiosa

### Islam (religione maggioritaria)

| Aspetto          | Indicazione              |
| -------------- | ------------------------ |
| Preghiere del venerdì | Le riunioni possono interrompersi |
| Ramadan        | Evitare di mangiare in pubblico |
| Maiale/alcol   | Non offrire ai musulmani |
| Mano destra    | Usare per dare/ricevere  |
| Codice di abbigliamento | Apprezzato uno stile conservativo |
| Moschee        | Togliere le scarpe, coprirsi |

### Induismo (Bali)

| Aspetto | Indicazione           |
| ------------- | ----------------------- |
| Templi        | Abbigliamento adeguato richiesto |
| Offerte       | Non calpestarle         |
| Cerimonie     | Mostrare rispetto       |
| Mestruazioni  | Ingresso ai templi limitato |
| Giorni sacri  | Alcune chiusure         |

<InfoCard variant="warning" title="Temple Dress Code">
**Visitare i templi balinesi:**

- Sarong obbligatorio (spesso fornito)
- Niente pantaloncini/gonne corte
- Spalle coperte
- Fascia intorno alla vita
- Spesso togliere le scarpe

Molti templi offrono noleggi disponibili.

</InfoCard>

## Cosa fare e non fare

### Da fare

| Cosa fare               | Perché              |
| ------------------- | ------------------- |
| Sorridi spesso      | Apre le porte       |
| Usa i titoli        | Mostra rispetto     |
| Accetta l'ospitalità | Rifiutare può offendere |
| Impara le basi del Bahasa | Molto apprezzato |
| Sii paziente        | La fretta è maleducata |
| Vestiti con modestia | Rispetta le norme locali |
| Togli le scarpe     | Quando entri nelle case |

### Da non fare

| Cosa non fare          | Perché                   |
| ------------------ | ------------------------ |
| Perdere la calma   | Causa perdita della faccia |
| Indicare con il dito | Usa invece il pollice   |
| Mostrare le suole dei piedi | Considerato irrispettoso |
| Toccare la testa   | Parte sacra del corpo    |
| Affrettare le relazioni | La fiducia richiede tempo |
| Criticare in pubblico | Causa imbarazzo        |
| Essere troppo rumorosi | La discrezione è apprezzata |
