# Etiket Budaya Indonesia 2026: Panduan Ekspat

Indonesia memiliki tradisi budaya yang kaya. Memahami adat setempat akan membantu Anda membangun hubungan yang lebih baik dan menghindari kesalahpahaman.

## Nilai-Nilai Budaya Inti

<InfoCard variant="note" title="Key Values">
**Masyarakat Indonesia menjunjung tinggi:**

- **Harmoni** - Menghindari konflik, menjaga kedamaian
- **Rasa Hormat** - Kepada orang yang lebih tua, hierarki, agama
- **Komunitas** - Kelompok di atas individu
- **Muka** - Menjaga martabat, menghindari rasa malu
- **Kesabaran** - "Jam karet" itu nyata
- **Keramahan** - Menyambut tamu dengan hangat

Memahami nilai-nilai ini menjelaskan banyak adat istiadat.

</InfoCard>

---

## Etiket Sosial

### Sapaan

| Situasi | Sapaan yang Tepat |
| ----------------- | ------------------------------- |
| Formal/Bisnis | Sedikit membungkuk, jabat tangan |
| Santai | Senyum, lambaian, "Halo" |
| Orang yang lebih tua | Sedikit membungkuk, nada hormat |
| Muslim yang taat | Jabat tangan sesama jenis lebih disukai |
| Orang Bali | "Om Swastiastu" (sapaan) |

### Kontak Fisik

| Perilaku | Kepantasan |
| -------------------- | ------------------------- |
| Jabat tangan | Normal (sesama jenis) |
| Tepukan di punggung | Di antara teman |
| Menyentuh kepala | Jangan pernah (sakral) |
| Menunjuk dengan jari | Hindari (gunakan ibu jari) |
| Tangan kiri untuk memberi | Hindari (gunakan tangan kanan) |
| Kemesraan di depan umum | Secukupnya saja |

<InfoCard variant="warning" title="The Head">
**Kepala itu sakral** dalam budaya Indonesia.

- Jangan pernah menyentuh kepala seseorang
- Termasuk anak-anak dan teman
- Bahkan tepukan bercanda pun tidak sopan
- Jasa penataan rambut adalah pengecualian (konteks profesional)
</InfoCard>

### Pertukaran Kartu Nama

| Langkah | Caranya |
| -------------- | ----------------------------------- |
| Memberi | Gunakan kedua tangan |
| Menerima | Gunakan kedua tangan |
| Membaca | Pelajari kartu sebentar |
| Menyimpan | Letakkan dengan hati-hati, jangan di saku belakang |
| Selama rapat | Biarkan terlihat di atas meja |

### Hubungan Bisnis

<InfoCard variant="tip" title="Relationship First">
**Di Indonesia:**

- Bisnis sering mengikuti hubungan
- Obrolan ringan sebelum membahas bisnis itu penting
- Rapat makan siang/malam penting
- Membangun kepercayaan membutuhkan waktu
- Hubungan personal itu penting

Jangan terburu-buru ke bisnis - investasikan waktu untuk hubungan terlebih dahulu.

</InfoCard>

## Kepekaan Agama

### Islam (Agama Mayoritas)

| Pertimbangan | Panduan |
| -------------- | ------------------------ |
| Salat Jumat | Rapat mungkin jeda |
| Ramadan | Hindari makan di depan umum |
| Babi/alkohol | Jangan tawarkan kepada Muslim |
| Tangan kanan | Gunakan untuk memberi/menerima |
| Cara berpakaian | Pakaian konservatif dihargai |
| Masjid | Lepas sepatu, tutup aurat |

### Hindu (Bali)

| Pertimbangan | Panduan |
| ------------- | ----------------------- |
| Pura | Pakaian yang pantas wajib |
| Sesajen | Jangan dilangkahi |
| Upacara | Tunjukkan rasa hormat |
| Menstruasi | Dilarang masuk pura |
| Hari suci | Beberapa tutup |

<InfoCard variant="warning" title="Temple Dress Code">
**Mengunjungi pura di Bali:**

- Sarung wajib (sering disediakan)
- Dilarang celana pendek/rok pendek
- Bahu tertutup
- Selempang di pinggang
- Sering harus melepas sepatu

Banyak pura menyediakan penyewaan.

</InfoCard>
