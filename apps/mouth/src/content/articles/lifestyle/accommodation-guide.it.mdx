## Consigli per il contratto di affitto

### Termini chiave da includere

| Termine | Cosa controllare |
| ----------- | ---------------------------- |
| Durata | Date di inizio/fine chiare |
| Importo dell'affitto | Totale e piano dei pagamenti |
| Deposito | Importo e condizioni di restituzione |
| Utenze | Chi paga cosa |
| Manutenzione | Responsabilità per le riparazioni |
| Risoluzione | Periodo di preavviso, penali |
| Inventario | Elenco degli articoli inclusi |

<InfoCard variant="tip" title="Get It in Writing">
Anche gli affitti informali dovrebbero avere:
- Accordo scritto (può essere semplice)
- Ricevute di pagamento
- Documentazione delle condizioni
- Recapiti del proprietario

I contratti indonesiani sono esecutivi - fanne uno!

</InfoCard>

## Ammobiliato vs Non ammobiliato

### Bali/Aree turistiche

La maggior parte degli affitti è **completamente ammobiliata**:

- Letto, materasso, biancheria
- Mobili del soggiorno
- Cucina attrezzata
- Aria condizionata
- Acqua calda
- Spesso include WiFi

### Jakarta/Città

Mix di opzioni:

- Appartamenti serviti: completamente ammobiliati
- Appartamenti normali: arredamento di base
- Case: possono essere non ammobiliate

## Risparmio sul lungo termine

| Durata | Sconto tipico |
| --------- | ---------------- |
| Mensile | Prezzo intero |
| 3 mesi | 5-10% di sconto |
| 6 mesi | 15-25% di sconto |
| 12 mesi | 25-40% di sconto |

<InfoCard variant="tip" title="Negotiate!">

  Consigli per tariffe migliori: - Chiedi direttamente (non accettare il primo
  prezzo) - Offri un periodo più lungo - Paga in anticipo se possibile - Bassa
  stagione = offerte migliori - Direttamente con il proprietario = nessuna
  commissione di agenzia
</InfoCard>
