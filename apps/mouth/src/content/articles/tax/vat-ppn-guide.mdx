# VAT (PPN) Indonesia 2026: 11% Effective / 12% Luxury Rate & Compliance Guide

Indonesia's Value Added Tax — PPN (*Pajak Pertambahan Nilai*) — moved to a statutory **12%** rate on 1 January 2025 under **PMK 131/2024**, while preserving an **11% effective rate** for general goods and services through the `11/12` *DPP Nilai Lain* tax base. Registration as a **PKP** (*Pengusaha Kena Pajak*) is mandatory once annual gross turnover exceeds **IDR 4.8 billion**, triggering Coretax e-Faktur invoicing and monthly SPT Masa PPN obligations.

<KeyTakeaway>
  **TL;DR:** Under **PMK 131/2024**, general goods and services pay an
  **effective 11% PPN** (`12% × 11/12 DPP Nilai Lain`), while luxury goods pay
  the full **12%** rate. Mandatory PKP registration starts above **IDR 4.8B**
  annual turnover, with monthly SPT Masa PPN payment and filing due by the **end
  of the following month** via Coretax e-Faktur. Late payments incur variable
  monthly **KMK interest rates** plus statutory 1% e-Faktur administrative
  fines where applicable.
</KeyTakeaway>

<InfoCard variant="warning" title="2026 VAT Update (PMK 131/2024 — pajak.go.id)">
**How the 12% Statutory vs. 11% Effective PPN Structure Works:**

Since 1 January 2025, Indonesia's statutory PPN rate is **12%**, but **PMK 131/2024** applies an alternative tax base (**DPP Nilai Lain** = 11/12 of selling price) for ordinary non-luxury goods and services:

- **General Goods & Services**: `12% × (11/12)` = **11% effective VAT**
- **Luxury Goods (PPnBM category)**: **12% full rate** (on full selling price, without the 11/12 reduction)
- **Tax Invoices (Faktur Pajak)**: Must be issued electronically through **Coretax e-Faktur**
- **Filing & Payment**: Due by the **end of the following month** (PMK 81/2024)

</InfoCard>

## VAT Registration

### Who Must Register?

<InfoCard variant="note" title="PKP Registration Threshold">
You must register as **PKP (Pengusaha Kena Pajak)** if:

- Gross turnover exceeds **IDR 4.8 billion/year**
- Or you **voluntarily register**

As PKP, you must:

- Charge VAT on sales
- Issue tax invoices (Faktur Pajak)
- File monthly VAT returns
- Can claim input VAT credits
</InfoCard>

## VAT Calculation

<Calculator
  title="VAT (PPN) Calculator — PMK 131/2024"
  description="Calculate 11% effective VAT (general goods/services via 11/12 DPP) or 12% full luxury VAT"
  fields={[
    {
      id: "amount",
      label: "Transaction Amount (IDR)",
      type: "number",
      defaultValue: 100000000,

      step: 1000000,

      options: [
        { value: "general", label: "General Goods / Services (11% effective via 11/12 DPP)" },
        { value: "luxury", label: "Statutory Luxury Goods (12% full rate)" }
      ],
      defaultValue: "general"
    },
    {
      id: "type",
      label: "Transaction Type",
      type: "select",
      options: [
        { value: "exclusive", label: "Add VAT to price" },
        { value: "inclusive", label: "VAT included in price" }
      ],
      defaultValue: "exclusive"
    }
  ]}
  calculateResult={(values) => {
    const amount = Number(values.amount);
    const isLuxury = values.category === "luxury";
    const rate = isLuxury ? 0.12 : 0.11;

    let baseAmount, vatAmount, totalAmount;

    if (values.type === "exclusive") {
      baseAmount = amount;
      vatAmount = amount * rate;
      totalAmount = amount + vatAmount;
    } else {
      totalAmount = amount;
      baseAmount = amount / (1 + rate);
      vatAmount = totalAmount - baseAmount;
    }

    return {
      total: Math.round(vatAmount),
      breakdown: [
        { label: "Selling Price / Base (Excl. VAT)", amount: Math.round(baseAmount) },
        { label: isLuxury ? "Luxury PPN (12%)" : "Effective PPN (11% = 12% × 11/12 DPP)", amount: Math.round(vatAmount) },
        { label: "Total with VAT", amount: Math.round(totalAmount) }
      ],
      currency: "IDR",
      note: isLuxury
        ? "Rate: 12% full (Luxury goods under PMK 131/2024)"
        : "Rate: 11% effective (12% statutory applied to 11/12 DPP Nilai Lain under PMK 131/2024)"
    };

## Tax Invoices (Faktur Pajak)

### E-Faktur System

<InfoCard variant="warning" title="E-Faktur Required">
All VAT-registered businesses must use the **e-Faktur** electronic invoicing system:

- Download e-Faktur application
- Register digital certificate
- Issue all invoices electronically
- Upload to DJP system
- Input VAT credits electronically
</InfoCard>

### Faktur Pajak Contents

| Required Field    | Description                  |
| ----------------- | ---------------------------- |
| Seller NPWP       | Your tax number              |
| Buyer NPWP        | Customer tax number          |
| Invoice number    | Sequential, system-generated |
| Transaction date  | Date of supply               |
| Description       | Goods/services detail        |
| DPP               | Tax base (price before VAT)  |
| PPN               | VAT amount                   |
| Digital signature | Electronic verification      |

## Input vs Output VAT

### How VAT Credits Work

| Transaction              | VAT Type   | Treatment               |
| ------------------------ | ---------- | ----------------------- |
| Sales to customers       | Output VAT | Collect and remit       |
| Purchases from suppliers | Input VAT  | Claim as credit         |
| Net position             | Difference | Pay if output > input   |
| Net credit               | Difference | Carry forward or refund |

### Example Monthly Calculation

| Description           | Amount   |
| --------------------- | -------- |
| Output VAT (sales)    | IDR 110M |
| Input VAT (purchases) | IDR 55M  |
| Net VAT payable       | IDR 55M  |

## Common Issues

### VAT Problems to Avoid

| Issue              | Consequence             |
| ------------------ | ----------------------- |
| Late filing        | IDR 500K penalty        |
| Incorrect invoices | Credits disallowed      |
| Missing invoices   | Unable to claim credits |
| Wrong NPWP         | Invoice rejected        |
| Late payment       | Interest penalties      |

### Input VAT Credit Rules

<InfoCard variant="warning" title="Claimable Input VAT">
Not all input VAT is creditable. Credits are **denied** for:

- Entertainment expenses
- Non-business purchases
- Purchases without valid tax invoice
- Purchases from non-PKP suppliers
- Luxury goods (cars, etc.)
</InfoCard>

---

## VAT Refund

### When Refund Available

- Output VAT consistently less than input VAT
- Export businesses (zero-rated sales)
- New investments with large input VAT

### Refund Process

1. File annual or special refund request
2. Tax audit typically required
3. Processing time: 1-12 months
4. Full documentation required
