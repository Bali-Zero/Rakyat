    let rate = "22%";

    if (values.type === "umkm_eligible" && revenue <= 4800000000) {
      tax = revenue * 0.005;
      rate = "0,5% del fatturato (PT PMA e nuove PT/CV escluse ex PP 20/2026)";
    } else if (values.type === "art31e" && revenue > 0 && revenue <= 50000000000) {
      const discountedShare = Math.min(1, 4800000000 / revenue);
      const discountedProfit = profit * discountedShare;
      const regularProfit = profit - discountedProfit;
      tax = discountedProfit * 0.11 + regularProfit * 0.22;
      rate = revenue <= 4800000000 ? "11% (Sconto pieno 50% Art. 31E)" : "Aliquota mista Art. 31E (11% + 22%)";

## Imposta Definitiva per PMI (PP 55/2022 & Esclusione PP 20/2026)

<InfoCard variant="warning" title="AGGIORNAMENTO CRITICO — PP 20/2026 (In vigore dal 22 aprile 2026)">
Ai sensi del **PP 55/2022**, i contribuenti con fatturato lordo inferiore a **4,8 miliardi di IDR/anno** potevano accedere all'imposta sostitutiva dello 0,5% entro i seguenti limiti temporali massimi:

- **3 anni** per società per azioni ordinarie (**PT**)
- **4 anni** per **CV, Firma e Koperasi**
- **7 anni** per persone fisiche (**Orang Pribadi**)

**Aggiornamento PP 20/2026 (in vigore dal 22 aprile 2026):** le società **PT ordinarie, PT PMA, CV e Firma** a più soci sono **escluse** dal nuovo accesso al regime finale 0,5%. Le PT/CV domestiche preesistenti già nel regime PP 55/2022 completano solo la finestra residua di 3 anni/4 anni; le PT PMA con fatturato fino a **50 miliardi di IDR** applicano invece l'**Art. 31E UU HPP** (11% effettivo sulla quota proporzionale ai 4,8 miliardi di ricavi, 22% sulla parte eccedente).

</InfoCard>

### Esempio Regime Finale 0,5% (Transitorio / Persone Fisiche)

| Ricavo Mensile | Imposta Dovuta |
| --------------- | -------- |
| 100 milioni di IDR | 500.000 IDR |
| 200 milioni di IDR | 1 milione di IDR |
| 400 milioni di IDR | 2 milioni di IDR |

<InfoCard variant="note" title="Scadenze di Presentazione">

**SPT Tahunan Badan** (Dichiarazione Annuale Imposta d'Impresa): - **Scadenza**: 4 mesi dopo la chiusura dell'esercizio fiscale - **Per l'anno solare**: 30 aprile - **Proroga**: Fino a 2 mesi possibili - **Metodo**: e-Filing obbligatorio

## Pricing di Trasferimento

<InfoCard variant="warning" title="Operazioni tra Parti Correlate">
L'Indonesia ha regole rigorose sul **pricing di trasferimento** per le operazioni tra parti correlate:

- Devono essere a prezzi **arm's length** (a distanza armata)
- **Documentazione richiesta** (Master File, Local File)
- **Country-by-Country Reporting** per grandi gruppi
- **Sanzioni** per mancata conformità

Collabora con consulenti fiscali qualificati per le operazioni tra parti correlate.

</InfoCard>

### Requisiti di Documentazione

| Report      | Richiesto Per        | Soglia                |
| ----------- | ------------------- | ------------------------ |
| Master File | Grandi contribuenti     | Ricavo IDR 50 miliardi+         |
| Local File  | Affari tra parti correlate | Qualsiasi transazione rilevante |
| CbC Report  | Multinazionali      | Ricavo gruppo €750 milioni+     |

## Problemi Comuni per le Società Esterne

### Considerazioni PT PMA

1. **Thin Capitalization** - Limiti rapporto debito/capitale (4:1)
2. **Pricing di Trasferimento** - Ispezione operazioni tra parti correlate
3. **Imposte di Trattenuta** - Pagamenti a filiali estere
4. **Stabilimento Permanente** - Necessaria strutturazione attenta
5. **Convenzioni Fiscali** - Verificare applicabilità
