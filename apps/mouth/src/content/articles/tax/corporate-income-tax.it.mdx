## Imposta Definitiva per PMI (PP 55/2022)

<InfoCard variant="tip" title="Semplificato per Piccole Imprese">
Le imprese con un fatturato lordo inferiore a **4,8 miliardi di Rupiah/anno** possono utilizzare l'imposta definitiva semplificata:

- **Aliquota**: 0,5% del fatturato lordo
- **Nessun calcolo complesso**
- **Pagamento mensile**
- **Si applica a**: PT, CV, individui con attività commerciale
- **Durata**: Massimo 7 anni per PT, 4 anni per CV/individui

Dopo il periodo massimo, si applicano le aliquote regolari.

</InfoCard>

### Esempio Imposta PMI

| Ricavo Mensile | Imposta Dovuta |
| --------------- | -------- |
| 100 milioni di IDR | 500.000 IDR |
| 200 milioni di IDR | 1 milione di IDR |
| 400 milioni di IDR | 2 milioni di IDR |

## Requisiti di Presentazione dell'Imposta

### Dichiarazione Annuale Imposta d'Impresa

<InfoCard variant="note" title="Scadenze di Presentazione">

**SPT Tahunan Badan** (Dichiarazione Annuale Imposta d'Impresa): - **Scadenza**: 4 mesi dopo la chiusura dell'esercizio fiscale - **Per l'anno solare**: 30 aprile - **Proroga**: Fino a 2 mesi possibili - **Metodo**: e-Filing obbligatorio

</InfoCard>

### Obblighi Mensili

| Obbligo | Scadenza                | Descrizione             |
| ---------- | ----------------------- | ----------------------- |
| PPh 21     | 10 del mese successivo | Trattenuta dipendenti    |
| PPh 23     | 10 del mese successivo | Trattenuta servizi       |
| PPh 25     | 15 del mese successivo | Rate anticipate ICI      |
| PPh 4(2)   | 10 del mese successivo | Elementi imposta definitiva |
| IVA (PPN)  | Fine mese successivo    | Se registrato per l'IVA  |

## Pricing di Trasferimento

<InfoCard variant="warning" title="Operazioni tra Parti Correlate">
L'Indonesia ha regole rigorose sul **pricing di trasferimento** per le operazioni tra parti correlate:

- Devono essere a prezzi **arm's length** (a distanza armata)
- **Documentazione richiesta** (Master File, Local File)
- **Country-by-Country Reporting** per grandi gruppi
- **Sanzioni** per mancata conformità

Collabora con consulenti fiscali qualificati per le operazioni tra parti correlate.

</InfoCard>

### Requisiti di Documentazione

| Report      | Richiesto Per        | Soglia                |
| ----------- | ------------------- | ------------------------ |
| Master File | Grandi contribuenti     | Ricavo IDR 50 miliardi+         |
| Local File  | Affari tra parti correlate | Qualsiasi transazione rilevante |
| CbC Report  | Multinazionali      | Ricavo gruppo €750 milioni+     |

## Problemi Comuni per le Società Esterne

### Considerazioni PT PMA

1. **Thin Capitalization** - Limiti rapporto debito/capitale (4:1)
2. **Pricing di Trasferimento** - Ispezione operazioni tra parti correlate
3. **Imposte di Trattenuta** - Pagamenti a filiali estere
4. **Stabilimento Permanente** - Necessaria strutturazione attenta
5. **Convenzioni Fiscali** - Verificare applicabilità
