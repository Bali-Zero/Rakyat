  calculateResult={(values) => {
    const revenue = Number(values.revenue);
    const expenses = Number(values.expenses);
    const profit = Math.max(0, revenue - expenses);

    let tax = 0;
    let rate = "22%";

    if (values.type === "umkm_eligible" && revenue <= 4800000000) {
      tax = revenue * 0.005;
      rate = "0.5% dari omset bruto (PT PMA & PT/CV baru dikecualikan PP 20/2026)";
    } else if (values.type === "art31e" && revenue > 0 && revenue <= 50000000000) {
      const discountedShare = Math.min(1, 4800000000 / revenue);
      const discountedProfit = profit * discountedShare;
      const regularProfit = profit - discountedProfit;
      tax = discountedProfit * 0.11 + regularProfit * 0.22;
      rate = revenue <= 4800000000 ? "11% (Fasilitas penuh 50% Pasal 31E)" : "Tarif campuran Pasal 31E (11% + 22%)";
    } else if (values.type === "public") {
      tax = profit * 0.19;
      rate = "19%";
    } else {
      tax = profit * 0.22;
      rate = "22%";
    }

    return {
      total: Math.round(tax),

## Pajak Final UMKM (PP 55/2022 & Pengecualian PP 20/2026)

<InfoCard variant="warning" title="PEMBARUAN PENTING — PP 20/2026 (Berlaku 22 April 2026)">
Berdasarkan **PP 55/2022**, wajib pajak dengan omset bruto di bawah **IDR 4,8 miliar/tahun** memiliki batas waktu maksimal skema final 0,5%:

- **3 tahun** untuk Perseroan Terbatas biasa (**PT**)
- **4 tahun** untuk **CV, Firma, dan Koperasi**
- **7 tahun** untuk wajib pajak **Orang Pribadi**

**Pembaruan Penting PP 20/2026 (berlaku 22 April 2026):** **PT biasa, PT PMA, CV, dan Firma** berpemegang saham jamak **dikecualikan** dari penggunaan baru tarif final 0,5%. PT/CV domestik lama yang sudah menggunakan PP 55/2022 sebelum PP 20/2026 hanya menyelesaikan sisa masa 3 tahun/4 tahun mereka; PT PMA dengan omzet hingga **IDR 50 miliar** menerapkan fasilitas **Pasal 31E UU HPP** (efektif 11% atas porsi omzet s.d. IDR 4,8 miliar, 22% selebihnya).

</InfoCard>

### Ilustrasi Pajak Final 0,5% (Masa Transisi / Orang Pribadi)

| ------------------ | -------------- |
| IDR 100M           | IDR 500K       |

## Penentuan Harga Transfer

<InfoCard variant="warning" title="Transaksi Pihak Terkait">
Indonesia memiliki aturan **penentuan harga transfer** yang ketat untuk transaksi antara pihak terkait:

- Harus pada harga **arm's length**
- **Dokumentasi diperlukan** (Master File, Local File)
- **Laporan Negara per Negara** untuk kelompok besar
- **Sanksi** untuk ketidakpatuhan

Bekerja dengan penasihat pajak yang berkualitas untuk transaksi pihak terkait.

</InfoCard>

### Kebutuhan Dokumentasi

| Laporan      | Diperlukan Untuk        | Ambang Batas                |
| ------------ | ------------------------ | --------------------------- |
| Master File  | Wajib pajak besar        | Pendapatan IDR 50Miliar+    |
| Local File   | Transaksi pihak terkait  | Setiap transaksi material    |
| Laporan CbC  | Multinasional            | Pendapatan kelompok €750M+  |

## Masalah Umum untuk Perusahaan Asing

### Pertimbangan PT PMA

1. **Thin Capitalization** - Batas rasio utang/ekuitas (4:1)
2. **Penentuan Harga Transfer** - Pemeriksaan transaksi pihak terkait
3. **Pajak Pemotongan** - Pembayaran ke afiliasi asing
4. **Kantor Permanen** - Perlu perancangan hati-hati
5. **Perjanjian Pajak** - Periksa kelayakan
