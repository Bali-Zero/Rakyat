## Memahami PPh 29 dan PPh 28

Pada akhir setiap tahun pajak, perusahaan Indonesia harus merekonsiliasi kewajiban pajak aktual dengan prepayment bulanan (PPh 25) dan kredit pajak pemotongan (PPh 22, 23, 24) yang terakumulasi sepanjang tahun. Rekonsiliasi ini menghasilkan salah satu dari dua hasil:

- **PPh 29 (Kurang Bayar)**: Kewajiban pajak aktual Anda melebihi jumlah yang telah Anda bayar. Anda harus membayar tambahan pajak.
- **PPh 28 (Lebih Bayar)**: Total pembayaran Anda melebihi kewajiban pajak aktual Anda. Anda telah membayar lebih dan berhak atas pengembalian dana atau kredit.

Bagi perusahaan PT PMA yang beroperasi di Indonesia, memahami penyelesaian tahunan ini sangat penting untuk perencanaan arus kas, pelaporan keuangan, dan kepatuhan.

## Rumus Penyelesaian Pajak Tahunan

### Perhitungan Langkah demi Langkah

**Langkah 1: Menghitung Pajak Penghasilan Badan Tahunan**

```
Gross Revenue (Peredaran Bruto)
- Cost of Goods Sold (Harga Pokok Penjualan)
= Gross Profit (Laba Kotor)

Gross Profit
- Operating Expenses (Biaya Operasional)
- Depreciation & Amortization
- Other Allowable Deductions
= Taxable Income (Penghasilan Kena Pajak)

PPh Badan Terutang = Taxable Income x 22%
```

**Langkah 2: Mengidentifikasi Seluruh Kredit Pajak**

| Jenis Kredit | Sumber                                        | Jumlah Umum       |
| ----------- | --------------------------------------------- | -------------------- |
| PPh 22      | Dipotong atas impor oleh bea cukai                | 2.5% dari nilai impor |
| PPh 23      | Dipotong oleh klien atas pembayaran jasa       | 2% dari nilai jasa  |
| PPh 24      | Pajak luar negeri yang dibayar (dengan batas perjanjian)       | Bervariasi menurut negara    |
| PPh 25      | Angsuran bulanan yang dibayar sepanjang tahun | 12 x jumlah bulanan  |

**Langkah 3: Menghitung Penyelesaian**

```
PPh 29 (or PPh 28) = PPh Badan Terutang - PPh 22 - PPh 23 - PPh 24 - Total PPh 25

If result is POSITIVE = PPh 29 (underpayment, you owe more)
If result is NEGATIVE = PPh 28 (overpayment, you are owed a refund)
If result is ZERO = Nihil (no additional payment or refund)
```

## Contoh Komprehensif: Perhitungan PPh 29

### PT Bali Sunrise Ventures (PT PMA)

**Ringkasan Keuangan 2025:**

| Pos               | Jumlah (IDR)      |
| ------------------ | ----------------- |
| Pendapatan Bruto      | 12,000,000,000    |
| Harga Pokok Penjualan | (7,200,000,000)   |
| **Laba Kotor**   | **4,800,000,000** |
| Biaya Operasional | (2,800,000,000)   |
| Penyusutan       | (400,000,000)     |
| Pengurangan Lainnya   | (200,000,000)     |
| **Penghasilan Kena Pajak** | **1,400,000,000** |

**Perhitungan Pajak dengan Fasilitas Pasal 31E:**

Karena pendapatan sebesar IDR 12 miliar (di bawah IDR 50 miliar), perusahaan memenuhi syarat untuk diskon 50% Pasal 31E atas bagian proporsional:

```
Discounted portion: (4.8B / 12B) x 1.4B = IDR 560,000,000
Full-rate portion: 1.4B - 560M = IDR 840,000,000

Tax on discounted portion: 560M x 11% = IDR 61,600,000
Tax on full-rate portion: 840M x 22% = IDR 184,800,000

PPh Badan Terutang = IDR 246,400,000
```

**Kredit Pajak Selama 2025:**

| Kredit                              | Jumlah (IDR)    |
| ----------------------------------- | --------------- |
| PPh 22 (impor)                    | 18,000,000      |
| PPh 23 (penghasilan jasa)             | 24,000,000      |
| PPh 24 (kredit pajak luar negeri)         | 0               |
| PPh 25 (12 bulan x IDR 15,000,000) | 180,000,000     |
| **Total Kredit**                   | **222,000,000** |

**Penyelesaian:**

```
PPh 29 = IDR 246,400,000 - IDR 222,000,000
PPh 29 = IDR 24,400,000 (underpayment)
```

PT Bali Sunrise Ventures harus membayar IDR 24,400,000 sebagai PPh 29 sebelum melaporkan SPT Tahunan 2025 paling lambat 30 April 2026.

## Contoh Komprehensif: PPh 28 (Lebih Bayar)

### PT Nusa Digital Solutions (PT PMA)

**Ringkasan Keuangan 2025:**

| Pos               | Jumlah (IDR)      |
| ------------------ | ----------------- |
| Pendapatan Bruto      | 6,000,000,000     |
| Harga Pokok Penjualan | (3,000,000,000)   |
| **Laba Kotor**   | **3,000,000,000** |
| Biaya Operasional | (2,200,000,000)   |
| Penyusutan       | (300,000,000)     |
| Pengurangan Lainnya   | (100,000,000)     |
| **Penghasilan Kena Pajak** | **400,000,000**   |

**Perhitungan Pajak:**

Dengan Pasal 31E (pendapatan di bawah IDR 50 miliar):

```
Discounted portion: (4.8B / 6B) x 400M = IDR 320,000,000
Full-rate portion: 400M - 320M = IDR 80,000,000

Tax on discounted: 320M x 11% = IDR 35,200,000
Tax on full-rate: 80M x 22% = IDR 17,600,000

PPh Badan Terutang = IDR 52,800,000
```

**Kredit Pajak Selama 2025:**

| Kredit                             | Jumlah (IDR)    |
| ---------------------------------- | --------------- |
| PPh 23 (penghasilan jasa)            | 30,000,000      |
| PPh 25 (12 bulan x IDR 8,000,000) | 96,000,000      |
| **Total Kredit**                  | **126,000,000** |

**Penyelesaian:**

```
PPh 28 = IDR 52,800,000 - IDR 126,000,000
PPh 28 = (IDR 73,200,000) - OVERPAYMENT
```

PT Nusa Digital Solutions membayar lebih sebesar IDR 73,200,000. Perusahaan dapat mengajukan pengembalian dana atau mengkompensasikan kredit ini ke depan.

**Mengapa hal ini terjadi?** Angsuran PPh 25 didasarkan pada tahun sebelumnya ketika perusahaan lebih menguntungkan. Penghasilan tahun berjalan turun, tetapi angsuran bulanan tidak dikurangi.

## PPh 29: Proses Pembayaran

### Linimasa

| Langkah                 | Waktu              | Tindakan                               |
| -------------------- | ----------------- | ------------------------------------ |
| Penutupan akhir tahun     | Januari           | Tutup pembukuan untuk tahun sebelumnya    |
| Laporan keuangan | Januari-Februari  | Siapkan laporan keuangan auditan |
| Perhitungan pajak      | Februari-Maret    | Hitung PPh Badan Terutang         |
| Pembayaran PPh 29       | Sebelum pelaporan SPT | Bayar kekurangan pembayaran melalui e-Billing       |
| Pelaporan SPT Tahunan   | Paling lambat 30 April       | Lapor SPT tahunan di CoreTax        |

### Cara Membayar PPh 29

1. **Hitung jumlah PPh 29 yang tepat** dari perhitungan pajak Anda
2. **Masuk ke CoreTax** di [coretaxdjp.pajak.go.id](https://coretaxdjp.pajak.go.id)
3. **Buat kode billing:**
   - Arahkan ke Pembayaran > Buat Kode Billing
   - Jenis pajak: PPh Pasal 29 (411126)
   - Masa pajak: Desember (atau 12)
   - Tahun pajak: Tahun sebelumnya (misalnya, 2025 untuk pelaporan pada 2026)
   - Jumlah: Perhitungan PPh 29 Anda
4. **Bayar melalui bank** menggunakan kode billing
5. **Simpan BPN** (Bukti Penerimaan Negara) sebagai bukti pembayaran
6. **Masukkan nomor BPN** saat melaporkan SPT Tahunan Anda di CoreTax

**Penting**: PPh 29 harus dibayar SEBELUM menyampaikan SPT Tahunan. CoreTax akan memvalidasi pembayaran selama pelaporan.

## PPh 28: Pilihan Kelebihan Bayar

Ketika rekonsiliasi tahunan Anda menunjukkan PPh 28 (lebih bayar), Anda memiliki tiga pilihan:

### Opsi 1: Kompensasi

**Cara kerja:** Kelebihan pembayaran diterapkan sebagai kredit terhadap angsuran PPh 25 tahun berikutnya atau kewajiban pajak final.

**Keunggulan:**

- Tidak memicu audit
- Manfaat langsung (mengurangi pembayaran bulanan tahun berikutnya)
- Sederhana, cukup pilih "Kompensasi" dalam pelaporan SPT Tahunan

**Kekurangan:**

- Kas tidak dikembalikan; hanya mengurangi kewajiban di masa depan
- Jika perusahaan tutup, kredit dapat hilang

**Paling cocok untuk:** Perusahaan yang diperkirakan akan terus beroperasi dan memiliki kewajiban pajak yang berkelanjutan.

### Opsi 2: Restitusi

**Cara kerja:** Anda meminta DJP untuk mengembalikan jumlah yang lebih dibayar langsung ke rekening bank Anda.

**Proses:**

1. Pilih "Restitusi" saat melaporkan SPT Tahunan
2. DJP memulai audit pajak (pemeriksaan pajak)
3. Audit meninjau seluruh pelaporan tahunan Anda, bukan hanya kelebihan pembayaran
4. Jika disetujui, DJP menerbitkan Surat Ketetapan Pajak Lebih Bayar (SKPLB)
5. Pengembalian dana diproses ke rekening bank terdaftar Anda

**Linimasa:** 3-12 bulan sejak tanggal pelaporan

**Keunggulan:**

- Kas aktual dikembalikan ke perusahaan Anda
- Memperbaiki arus kas

**Kekurangan:**

- Memicu audit pajak penuh
- Waktu pemrosesan lama
- Audit dapat menemukan masalah lain, yang berpotensi mengakibatkan ketetapan pajak tambahan
- Membutuhkan dokumentasi lengkap untuk seluruh tahun pajak

**Paling cocok untuk:** Perusahaan dengan kelebihan pembayaran signifikan (IDR 100 juta+) yang memiliki catatan pajak yang bersih dan terdokumentasi dengan baik.

### Opsi 3: Pengembalian Pendahuluan

**Cara kerja:** Bagi wajib pajak yang memenuhi syarat, DJP menawarkan proses pengembalian dana yang dipercepat dengan ruang lingkup audit yang dikurangi.

**Syarat kelayakan (Pasal 17C dan 17D UU KUP):**

- Wajib pajak orang pribadi dengan kelebihan pembayaran hingga IDR 100 juta
- Wajib pajak badan dengan kelebihan pembayaran hingga IDR 1 miliar
- Wajib pajak PKP (terdaftar PPN) dengan kelebihan pembayaran hingga IDR 1 miliar
- Wajib pajak "berisiko rendah" dengan riwayat kepatuhan yang baik

**Linimasa:** 1-3 bulan

**Keunggulan:**

- Jauh lebih cepat daripada pengembalian dana biasa
- Proses audit yang disederhanakan

**Kekurangan:**

- DJP tetap berhak melakukan audit penuh dalam waktu 5 tahun
- Jika audit penuh menemukan selisih, Anda mungkin harus mengembalikan pengembalian dana ditambah sanksi

## Penyebab Umum PPh 29 (Kurang Bayar)

Memahami mengapa kekurangan pembayaran terjadi membantu Anda merencanakan dengan lebih baik:

| Penyebab                     | Penjelasan                                                        | Pencegahan                           |
| ------------------------- | ------------------------------------------------------------------ | ------------------------------------ |
| Pertumbuhan pendapatan            | Pendapatan lebih tinggi dari tahun sebelumnya berarti pajak lebih tinggi tetapi PPh 25 sama | Tingkatkan PPh 25 secara sukarela pada pertengahan tahun |
| Keuntungan satu kali            | Penjualan aset, keuntungan selisih kurs, penerimaan asuransi                       | Sisihkan cadangan pajak segera  |
| Pengurangan berkurang        | Beban lebih rendah (misalnya, karyawan lebih sedikit, pemasaran lebih sedikit)             | Tinjau tren pengurang setiap triwulan    |
| PPh 25 berdasarkan tahun rugi | Tahun sebelumnya rugi, sehingga PPh 25 = 0                            | Laporkan PPh 25 estimasi secara sukarela    |
| Pengurangan kredit pajak      | Impor lebih rendah (PPh 22) atau pembayaran jasa lebih sedikit (PPh 23)          | Pantau kredit sepanjang tahun    |

## Penyebab Umum PPh 28 (Lebih Bayar)

| Penyebab                     | Penjelasan                                      | Solusi                        |
| ------------------------- | ------------------------------------------------ | --------------------------------- |
| Penurunan pendapatan           | Pendapatan lebih rendah dari tahun sebelumnya tetapi PPh 25 tinggi | Ajukan pengurangan PPh 25          |
| Peningkatan pengurang      | Beban lebih tinggi (ekspansi, karyawan baru)           | Rencanakan penyesuaian PPh 25            |
| PPh 25 berdasarkan tahun puncak | Tahun sebelumnya luar biasa                    | Ajukan pengurangan lebih awal         |
| Kredit pemotongan tinggi  | Banyak klien memotong PPh 23 atas faktur Anda | Kompensasikan atau ajukan pengembalian dana   |
| Rugi pajak                | Tahun berjalan menghasilkan kerugian                   | PPh 25 menjadi kelebihan pembayaran penuh |

## Tahun Rugi Pajak: Pertimbangan Khusus

Ketika PT PMA Anda melaporkan rugi pajak untuk tahun berjalan:

- **PPh Badan Terutang = IDR 0** (tidak ada pajak atas kerugian)
- **Seluruh pembayaran PPh 25 menjadi PPh 28** (kelebihan pembayaran penuh)
- **Seluruh kredit PPh 22 dan PPh 23 menjadi PPh 28**
- Kerugian pajak dapat dikompensasikan hingga 5 tahun (atau 10 tahun untuk industri tertentu)

**Contoh:**

- Rugi pajak 2025: (IDR 500,000,000)
- Total PPh 25 yang dibayar pada 2025: IDR 120,000,000
- Kredit PPh 22 dan 23: IDR 30,000,000
- PPh 28 (lebih bayar): IDR 150,000,000

**Keputusan:** Ajukan pengembalian dana (memicu audit) atau kompensasikan (mengurangi kewajiban 2026).

## Strategi Perencanaan Pajak Tahunan

### Meminimalkan Kejutan PPh 29

1. **Estimasi pajak triwulanan:** Hitung proyeksi pajak tahunan setiap triwulan, bukan hanya pada akhir tahun
2. **Pantau tren pendapatan:** Jika pendapatan tumbuh lebih cepat dari perkiraan, tingkatkan PPh 25 secara sukarela
3. **Pantau kredit pajak:** Pantau kredit PPh 22 dan PPh 23 sepanjang tahun
4. **Tinjau pengurang:** Pastikan semua pengurang yang diperbolehkan dimaksimalkan
5. **Pengaturan waktu beban:** Percepat beban yang diperbolehkan ke tahun berjalan jika menghadapi PPh 29 yang besar

### Menghindari PPh 28 yang Tidak Perlu

1. **Ajukan pengurangan PPh 25:** Jika pendapatan menurun, kurangi angsuran bulanan Anda
2. **Tinjau tarif pemotongan:** Negosiasikan dengan klien tentang pemotongan PPh 23 jika menimbulkan kredit berlebih
3. **Klaim manfaat perjanjian:** Gunakan perjanjian penghindaran pajak berganda untuk mengurangi PPh 24 dan meningkatkan kredit pajak luar negeri
4. **Rencanakan investasi:** Atur waktu belanja modal untuk menciptakan pengurang yang selaras dengan pola penghasilan

### Perencanaan Arus Kas

| Skenario                    | Dampak Arus Kas                           | Tindakan                                 |
| --------------------------- | ------------------------------------------ | -------------------------------------- |
| Perkiraan PPh 29 sebesar IDR 50Jt+ | Arus kas keluar signifikan pada Maret/April    | Sisihkan cadangan bulanan           |
| Perkiraan PPh 28 sebesar IDR 50Jt+ | Kas tertahan hingga pengembalian dana atau kompensasi | Ajukan pengurangan PPh 25 untuk tahun depan |
| Penghasilan fluktuatif             | Penyelesaian tidak dapat diprediksi                   | Pertahankan dana cadangan pajak              |

## Pertanyaan yang Sering Diajukan

### Kapan PPh 29 jatuh tempo?

PPh 29 harus dibayar SEBELUM menyampaikan SPT Tahunan Badan (SPT pajak perusahaan tahunan) Anda. Batas waktu SPT Tahunan adalah 30 April untuk wajib pajak badan. Dalam praktiknya, sebagian besar perusahaan membayar PPh 29 pada bulan Maret atau awal April dan melaporkan SPT segera setelahnya.

### Apa yang terjadi jika saya membayar lebih (PPh 28) bukannya kurang bayar?

Jika total pembayaran PPh 25 Anda ditambah kredit pajak melebihi kewajiban pajak aktual Anda, Anda memiliki PPh 28 (lebih bayar). Anda dapat mengajukan pengembalian dana (restitusi) dari DJP, yang melibatkan audit dan memakan waktu 3-12 bulan, atau mengkompensasikan kredit ke depan untuk mengurangi angsuran PPh 25 tahun depan.

### Apakah PPh 29 dapat dibayar secara mencicil?

Tidak, PPh 29 harus dibayar lunas sebelum menyampaikan SPT Tahunan Anda. Namun, jika jumlahnya sangat besar dan menimbulkan masalah arus kas, Anda dapat mengajukan penundaan ke DJP dalam kondisi tertentu, meskipun hal ini jarang diberikan dan mungkin memerlukan jaminan bank.

### Apa yang terjadi jika saya terlambat melaporkan SPT Tahunan?

Keterlambatan pelaporan SPT Tahunan Badan dikenakan sanksi sebesar IDR 1,000,000. Selain itu, setiap PPh 29 yang belum dibayar dikenakan bunga sebesar 2% per bulan sejak batas waktu hingga pembayaran. Jika keterlambatan melebihi 3 bulan, DJP dapat menerbitkan surat teguran resmi (STP - Surat Tagihan Pajak).

### Apakah PPh 29 memicu audit pajak?

PPh 29 sendiri tidak memicu audit. Namun, pengajuan PPh 28 dengan permintaan pengembalian dana memicu audit. Selain itu, fluktuasi signifikan dalam jumlah PPh 29 dari tahun ke tahun dapat menarik perhatian DJP selama pemilihan audit berbasis risiko.
