# Tech Startup in Indonesia 2026: Guida per Founder Esterne

L'Indonesia è il più grande ecosistema di startup del Sud-Est Asiatico, con unicorni come Gojek, Tokopedia e Traveloka. Ecco come i founder stranieri possono costruire qui.

## Perché l'Indonesia per la Tech?

- **270 milioni** di abitanti
- **Oltre 200 milioni** di utenti internet
- **Età mediana 29** - giovane e tecnologica
- **Classe media in crescita**
- **Mercato mobile-first**
- **Ecosistema VC attivo**

## Codici KBLI per la Tech

| Code  | Attività             | Note           |
| ----- | -------------------- | --------------- |
| 62011 | Sviluppo software   | App, piattaforme |
| 62012 | Integrazione sistemi | Enterprise      |
| 62021 | Consulenza IT        | Advisory        |
| 63111 | Elaborazione dati    | Analytics       |
| 63112 | Web hosting          | Infrastruttura  |
| 63122 | Portale web          | Marketplaces    |

<InfoCard variant="tip" title="Investimento Minore per la Tech">

Alcuni codici KBLI tech (specialmente 62011, 62012) possono avere requisiti di investimento inferiori rispetto allo standard di 10 miliardi di IDR. Controlla i requisiti attuali OSS per la tua attività specifica.

</InfoCard>

## Assunzioni in Indonesia

### Talento Locale

- Forte talento ingegneristico, specialmente a Jakarta
- Costi inferiori rispetto a Singapore
- Pool crescente di dipendenti esperti per startup
- La competenza inglese varia

### Fondamentali dell'Impiego

| Requirement          | Note                               |
| -------------------- | ----------------------------------- |
| BPJS Kesehatan       | Assicurazione sanitaria (obbligatoria)        |
| BPJS Ketenagakerjaan | Assicurazione lavoro (obbligatoria)    |
| Minimum wage         | Per provincia (Jakarta ~IDR 5M/mese) |
| Contracts            | A termine o indeterminato             |
| Severance            | Significativo in caso di licenziamenti             |

### Dipendenti Stranieri

Assumere talenti tech stranieri:

- RPTKA richiesto per ogni posizione
- Tassa DKP-TKA di 100 USD/mese
- Deve formare un controparte indonesiano
- Generalmente limitato a ruoli senior/specialisti

---

## Regolamenti Specifici per la Tech

### PSE (Operatore di Sistema Elettronico)

Tutte le piattaforme tech devono registrarsi:

- Obbligatorio per operare in Indonesia
- Requisiti di localizzazione dei dati
- Obblighi di moderazione del contenuto
- Clausole di accesso governativo

### Protezione Dati

- L'Indonesia ha una legge sulla protezione dei dati personali
- Requisiti per la gestione dei dati
- Obblighi di consenso e sicurezza
- Sanzioni per non conformità

### Specifico Fintech

Se costruisci fintech:

- Licenza OJK richiesta
- Programmi Sandbox disponibili
- Requisiti di capitale
- Report periodici regolari
