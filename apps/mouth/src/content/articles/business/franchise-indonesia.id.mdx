## Regulasi Waralaba

### Persyaratan Utama

<InfoCard variant="note" title="Government Registration">
**Waralaba wajib didaftarkan:**

- STPW (Surat Tanda Pendaftaran Waralaba)
- Wajib bagi franchisor
- Daftar dalam 30 hari setelah memulai
- Perpanjangan diperlukan

Beroperasi tanpa pendaftaran adalah ilegal.

</InfoCard>

### Kerangka Regulasi

| Regulasi             | Cakupan                          |
| -------------------- | -------------------------------- |
| Gov Reg 42/2007      | Definisi waralaba, persyaratan    |
| Minister Reg 71/2019 | Prosedur pendaftaran             |
| Menteri Perdagangan  | Pengawasan berkelanjutan         |

## Waralaba Asing

### Membawa Merek Asing ke Indonesia

<InfoCard variant="warning" title="Foreign Franchise Rules">
**Persyaratan untuk merek asing:**

- Perjanjian master franchise
- PT PMA biasanya diperlukan
- Daftarkan waralaba di Indonesia
- Mitra lokal mungkin diperlukan
- Persyaratan lokalisasi
- Aturan sumber lokal (80% untuk barang tertentu)

Franchisor asing harus menyesuaikan dengan regulasi Indonesia.

</InfoCard>

### Persyaratan Konten Lokal

| Persyaratan       | Detail                         |
| ----------------- | ------------------------------ |
| Produk lokal      | 80% untuk item F&B tertentu    |
| Kemitraan lokal   | Mungkin diperlukan untuk sektor tertentu |
| Manajemen lokal   | Keterlibatan orang Indonesia   |
| Pendaftaran       | Di Indonesia                   |
