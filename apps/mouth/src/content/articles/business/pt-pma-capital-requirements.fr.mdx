# Exigences de capital pour PT PMA : Ce que vous devez investir en 2026

L'investissement minimum de **10 milliards IDR** (environ 625 000 $ USD) pour une PT PMA est l'une des exigences les plus mal comprises. Examinons ce que cela signifie réellement.

## Les deux chiffres clés

| Exigence | Montant | Ce que cela signifie |
| -------------------- | ----------------------------- | ------------------------------------------------------------------------------------ |
| **Investissement total** | **> 10 milliards IDR** | Plan d'investissement hors terrains/bâtiments par KBLI à 5 chiffres / site (BKPM 5/2025) |
| **Capital versé** | **2,5 milliards IDR / société** | Capital minimum libéré au niveau de l'entreprise à la création (BKPM Reg. 5/2025 Art. 26) |

<InfoCard variant="important" title="Deux règles distinctes (Règl. BKPM 5/2025)">

Selon le **Règlement BKPM n° 5/2025**, le **capital versé minimum** est de **2,5 milliards IDR par société** (quel que soit le nombre d'actionnaires, bloqué 12 mois sauf dépenses opérationnelles documentées), tandis que l'**engagement d'investissement total** demeure **supérieur à 10 milliards IDR** (hors terrains et bâtiments dans la plupart des secteurs).

</InfoCard>

  calculateResult={(values) => {
    const cash = Number(values.cash);
    const equipment = Number(values.equipment);
    const working = Number(values.working);
    const property = Number(values.property);

    const qualifyingInvestment = cash + equipment + working;
    const minInvestment = 10000000000;
    const minPaidUp = 2500000000;
    const shortage = Math.max(0, minInvestment - qualifyingInvestment);
    const paidUpShortage = Math.max(0, minPaidUp - cash);

    const breakdown = [
      { label: "Capital versé (Espèces)", amount: cash },
      { label: "Équipements et machines", amount: equipment },
      { label: "Fonds de roulement", amount: working },

      { label: "Propriété/Terrain (Exclu du seuil >10 Mrd IDR)", amount: property }
    ];

    let note = "";
    if (cash < minPaidUp) {
      note = `Capital versé insuffisant de ${(paidUpShortage/1000000000).toFixed(2)} Mrd IDR. Minimum 2,5 Mrd IDR par société requis (BKPM 5/2025 Art. 26).`;
    } else if (qualifyingInvestment <= minInvestment) {

    }

      breakdown,
      currency: "IDR",

## Questions courantes sur le capital

<InfoCard variant="note" title="FAQ">
**Q: Ai-je besoin de 10 milliards IDR en espèces sur mon compte bancaire dès le premier jour ?**
R: Non. Selon le règlement BKPM 5/2025 Art. 26, le capital versé minimum est de **2,5 milliards IDR par société** (bloqué 12 mois sauf dépenses opérationnelles documentées). Le solde de l'engagement d'investissement (> 10 milliards IDR, hors terrains/bâtiments) peut être déployé progressivement en équipements, fonds de roulement et coûts opérationnels déclarés via LKPM.

**Q: Puis-je l'utiliser après le dépôt ?**
R: Le capital versé est soumis à une période de blocage de 12 mois, sauf décaissement pour des actifs ou opérations commerciales légitimes et documentés de la PT PMA.

**Q: Que faire si je ne peux pas atteindre > 10 milliards IDR ?**
R: Les options incluent :

- Joint-venture / PT PMDN avec un partenaire indonésien
- Bureau de représentation (KPPA — sans revenus locaux)
- Reporter la création jusqu'à ce qu'un plan > 10 milliards IDR soit viable

**Q: Existe-t-il un moyen de contourner le minimum ?**
R: Aucun moyen légitime. La réglementation impose clairement 2,5 milliards IDR de capital versé par société et > 10 milliards IDR d'investissement (hors terrains/bâtiments) pour une PT PMA.

</InfoCard>
