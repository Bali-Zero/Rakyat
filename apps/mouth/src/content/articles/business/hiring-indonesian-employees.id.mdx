### Kalkulator Biaya

<Calculator
  title="Total Employment Cost"
  description="Estimate employer total cost"
  fields={[
    {
      id: "gross",
      label: "Gross Monthly Salary (IDR)",
      type: "number",
      defaultValue: 15000000,
      min: 0,
      step: 1000000,
      suffix: "IDR"
    },
    {
      id: "thr",
      label: "Include THR Provision",
      type: "select",
      options: [
        { value: "yes", label: "Yes" },
        { value: "no", label: "No" }
      ],
      defaultValue: "yes"
    }
  ]}
  calculateResult={(values) => {
    const gross = Number(values.gross);

    // BPJS employer contributions
    const bpjsKesehatan = gross * 0.04; // 4% health
    const bpjsJKK = gross * 0.0024; // 0.24% min work accident
    const bpjsJKM = gross * 0.003; // 0.3% death
    const bpjsJHT = gross * 0.037; // 3.7% pension fund
    const bpjsJP = gross * 0.02; // 2% pension

    const totalBPJS = bpjsKesehatan + bpjsJKK + bpjsJKM + bpjsJHT + bpjsJP;

    // THR provision (1 month spread over 12)
    const thrProvision = values.thr === "yes" ? gross / 12 : 0;

    const totalMonthly = gross + totalBPJS + thrProvision;

    return {
      total: Math.round(totalMonthly),
      breakdown: [
        { label: "Gross Salary", amount: gross },
        { label: "BPJS Kesehatan (4%)", amount: Math.round(bpjsKesehatan) },
        { label: "BPJS JKK (0.24%)", amount: Math.round(bpjsJKK) },
        { label: "BPJS JKM (0.3%)", amount: Math.round(bpjsJKM) },
        { label: "BPJS JHT (3.7%)", amount: Math.round(bpjsJHT) },
        { label: "BPJS JP (2%)", amount: Math.round(bpjsJP) },
        { label: "THR Provision", amount: Math.round(thrProvision) },
        { label: "Total Monthly Cost", amount: Math.round(totalMonthly) }
      ],
      currency: "IDR",
      note: `Employer BPJS: ~10.24% of salary`
    };

}}

## Pendaftaran BPJS

### BPJS Kesehatan

<InfoCard variant="note" title="Health Insurance">
**Kontribusi:**
- Total: 5% dari gaji
- Pemberi kerja: 4%
- Karyawan: 1%

**Batas:** IDR 12 juta gaji pokok

**Cakupan:**

- Karyawan
- Pasangan
- Hingga 3 anak
- Anggota keluarga tambahan: +1% masing-masing

</InfoCard>

### BPJS Ketenagakerjaan

| Program                | Pemberi Kerja | Karyawan | Total   |
| ---------------------- | ------------- | -------- | ------- |
| JKK (Kecelakaan Kerja) | 0.24-1.74%    | 0%       | Bervariasi |
| JKM (Kematian)         | 0.30%         | 0%       | 0.30%   |
| JHT (Hari Tua)         | 3.70%         | 2%       | 5.70%   |
| JP (Pensiun)           | 2%            | 1%       | 3%      |

## Masa Percobaan

<InfoCard variant="warning" title="Probation Rules">
**Hanya untuk PKWTT (Permanen):**
- Maksimal 3 bulan
- Harus tertulis
- Gaji penuh selama masa percobaan
- Dapat mengakhiri dengan pemberitahuan selama masa percobaan
- Tidak ada pesangon jika diakhiri selama masa percobaan

**Untuk PKWT (Waktu Tertentu):**

- Masa percobaan TIDAK diperbolehkan
- Setiap klausul masa percobaan batal demi hukum

</InfoCard>

## Pertimbangan Penggajian

### Persyaratan Pembayaran

| Persyaratan | Detail               |
| ----------- | -------------------- |
| Frekuensi   | Bulanan (paling umum)|
| Metode      | Transfer bank        |
| Mata Uang   | IDR                  |
| Slip gaji   | Wajib                |
| Potongan    | BPJS, PPh 21, pinjaman |

### Pemotongan Pajak (PPh 21)

Pemberi kerja wajib:

1. Menghitung PPh 21 bulanan
2. Memotong dari gaji
3. Menyetor paling lambat tanggal 10 bulan berikutnya
4. Melaporkan paling lambat tanggal 20 bulan berikutnya
5. Menerbitkan bukti potong tahunan (1721-A1)
