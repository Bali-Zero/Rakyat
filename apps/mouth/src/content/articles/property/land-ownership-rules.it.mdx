# Regole sulla Proprietà Terreni in Indonesia 2026: Guida per Stranieri

Gli stranieri non possono possedere direttamente terreni in regime di piena proprietà in Indonesia. Tuttavia, esistono modi legali per garantire diritti sulla proprietà. Ecco la tua guida completa.

## La Regola Fondamentale

<InfoCard variant="warning" title="Restrizione Fondamentale">
**Legge indonesiana (Legge Agraria 1960):**

- Solo cittadini indonesi possono detenere **Hak Milik** (piena proprietà)
- Gli stranieri possono detenere determinati **diritti di utilizzo**
- Il terreno torna automaticamente allo stato se lo straniero detiene Hak Milik

Si tratta di una legge costituzionale - non può essere aggirata legalmente.

</InfoCard>

## Struttura PT PMA

### Come Funziona

1. **Costituisci PT PMA** - Società di investimento estera
2. **Registra attività immobiliare** - Nella licenza commerciale
3. **Acquista titolo HGB** - La società detiene il titolo
4. **Tu controlli la società** - Proprietà indiretta

### Vantaggi

| Beneficio             | Dettagli                    |
| ------------------- | -------------------------- |
| Uso commerciale      | Possibilità di affittare la proprietà      |
| Multiple proprietà | Nessun limite di singola proprietà   |
| Operazioni aziendali | Tutte le attività commerciali |
| Trasferibile        | Vendita delle quote, non della proprietà  |
| Finanziamento bancario      | Più facile da ottenere           |

### Svantaggi

| Sfida            | Dettagli                |
| -------------------- | ---------------------- |
| Costo di setup           | IDR 100-200M+          |
| Compliance continua   | Reportistica, tasse         |
| Requisiti di capitale | Investimento minimo     |
| Complessità           | Onere legale e amministrativo |
| Costi operativi        | Contabilità, licenze   |

## Accordi di Locazione

### Locazione a Lungo Termine

<InfoCard variant="tip" title="Alternativa Semplice">
**Locazione (Hak Sewa)** è spesso più semplice:

- Affitta il terreno dal proprietario indonesiano
- Termini tipici: 25-30 anni
- Possibilità di costruire con permesso
- Minore complessità rispetto alla PT PMA
- Nessun requisito di valore minimo

Molti espatri preferiscono questa opzione per la semplicità.

</InfoCard>

### Struttura di Locazione

| Elemento         | Termini Tipici                  |
| --------------- | ------------------------------ |
| Durata        | 25-30 anni                    |
| Prolungamento       | Spesso negoziabile               |
| Registrazione    | Accordo notarile            |
| Diritti di costruzione | Generalmente inclusi               |
| Miglioramenti    | Torna al proprietario o compensato |

## Cosa dei Nominees?

<InfoCard variant="warning" title="Accordi con Nominee">
**Nominee = Cittadino indonesiano detiene il titolo per lo straniero**

**La verità:**

- Comune ma **legalmente rischioso**
- La legge sui terreni non riconosce il nominee
- Il nominee può rivendicare la vera proprietà
- I tribunali potrebbero non proteggere lo straniero
- Può essere nullo se contestato

**Se usi un nominee:**

- Utilizza accordi legali completi
- Capisci di avere una PROTEZIONE LIMITATA
- Considera la PT PMA invece per sicurezza

</InfoCard>

### Rischi del Nominee

| Rischio                     | Conseguenza               |
| ------------------------ | ------------------------- |
| Il nominee rivendica la proprietà | Potresti perdere la proprietà         |
| Il nominee muore             | Complicazioni ereditarie |
| Debiti del nominee          | La proprietà può essere sequestrata    |
| Divorzio del nominee          | Il coniuge potrebbe rivendicare          |
| Contestazione legale          | L'accordo è nullo          |

## Titolo di Appartamento/Condominio

### Opzione Migliore per Stranieri

<InfoCard variant="note" title="Titolo Condominiale (Hak Milik Sarusun)">
**Gli appartamenti sono diversi!**

Gli stranieri possono detenere direttamente il titolo condominiale (HMSRS):

- PT PMA non necessaria
- KITAS non necessario (verifica lo sviluppo specifico)
- Si applicano ancora i requisiti di valore minimo
- Procedura transazionale più semplice

Molti stranieri scelgono gli appartamenti per la semplicità.

</InfoCard>

### Requisiti

| Requisito   | Dettagli                      |
| ------------- | ---------------------------- |
| Valore minimo | Varia per regione             |
| Tipo di edificio | Appartamenti/condominio solo       |
| Documentazione | Passaporto, contratto di acquisto |
| Registrazione  | Attraverso sviluppatore/BPN        |
