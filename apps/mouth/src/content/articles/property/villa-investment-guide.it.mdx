## Calcolatore d'investimento

<Calculator
  title="Villa Investment Analysis"
  description="Estimate investment costs and returns"
  fields={[
    {
      id: "purchasePrice",
      label: "Purchase/Lease Price (IDR)",
      type: "number",
      defaultValue: 5000000000,
      min: 1000000000,
      step: 500000000,
      suffix: "IDR"
    },
    {
      id: "bedrooms",
      label: "Bedrooms",
      type: "select",
      options: [
        { value: "2", label: "2 Bedroom" },
        { value: "3", label: "3 Bedroom" },
        { value: "4", label: "4 Bedroom" },
        { value: "5", label: "5+ Bedroom" }
      ],
      defaultValue: "3"
    },
    {
      id: "location",
      label: "Location",
      type: "select",
      options: [
        { value: "premium", label: "Premium (Seminyak, Canggu center)" },
        { value: "good", label: "Good (Pererenan, Umalas)" },
        { value: "developing", label: "Developing (Tabanan, North)" }
      ],
      defaultValue: "good"
    },
    {
      id: "occupancy",
      label: "Expected Occupancy %",
      type: "number",
      defaultValue: 60,
      min: 20,
      max: 90
    }
  ]}
  calculateResult={(values) => {
    const purchase = Number(values.purchasePrice);
    const bedrooms = Number(values.bedrooms);
    const occupancy = Number(values.occupancy) / 100;

    // Nightly rates by location and bedrooms
    const rateMap = {
      "premium-2": 3000000, "premium-3": 4500000, "premium-4": 6000000, "premium-5": 8000000,
      "good-2": 2000000, "good-3": 3000000, "good-4": 4000000, "good-5": 5500000,
      "developing-2": 1200000, "developing-3": 1800000, "developing-4": 2500000, "developing-5": 3500000
    };

    const nightlyRate = rateMap[`${values.location}-${values.bedrooms}`] || 2500000;
    const annualGross = nightlyRate * 365 * occupancy;

    // Operating costs
    const management = annualGross * 0.20; // 20% management
    const maintenance = 60000000; // General maintenance
    const utilities = 36000000; // Utilities avg
    const marketing = 24000000; // OTA fees, marketing
    const insurance = 12000000;
    const tax = annualGross * 0.10; // Rental income tax

    const totalCosts = management + maintenance + utilities + marketing + insurance + tax;
    const netIncome = annualGross - totalCosts;
    const grossYield = (annualGross / purchase) * 100;
    const netYield = (netIncome / purchase) * 100;

    return {
      total: netIncome,
      breakdown: [
        { label: "Gross Annual Revenue", amount: annualGross },
        { label: "Management (20%)", amount: -management },
        { label: "Maintenance", amount: -maintenance },
        { label: "Utilities", amount: -utilities },
        { label: "Marketing/OTA", amount: -marketing },
        { label: "Insurance", amount: -insurance },
        { label: "Rental Tax (10%)", amount: -tax },
        { label: "Net Annual Income", amount: netIncome }
      ],
      currency: "IDR",
      note: `Gross yield: ${grossYield.toFixed(1)}% | Net yield: ${netYield.toFixed(1)}%`
    };

}}

## Licenze per l'attività di locazione

<InfoCard variant="warning" title="Rental License Required">
La gestione di una villa in affitto richiede:
- Licenza **Pondok Wisata** per strutture ricettive di piccole dimensioni
- **TDUP** per attività di maggiori dimensioni
- Registrazione turistica
- Diverse autorizzazioni locali

Operare senza licenze comporta il rischio di sanzioni, chiusura e problemi relativi al visto.

</InfoCard>

### Requisiti delle licenze

| Licenza       | Per                   | Rilasciata da        |
| ------------- | --------------------- | -------------------- |
| Pondok Wisata | Piccole guesthouse    | Governo locale       |
| TDUP          | Strutture turistiche  | Dipartimento turismo |
| NIB           | Registrazione attività | OSS                 |
| Ambientale    | Impatto dell'attività | Dipartimento ambiente |

## Rischi comuni

### Rischi di mercato

- Eccesso di offerta nelle aree popolari
- Fluttuazioni del turismo
- Concorrenza degli hotel
- Cambiamenti normativi

### Rischi operativi

- Problemi di gestione
- Problemi di manutenzione
- Danni causati dagli ospiti
- Difficoltà con il personale

### Rischi legali

- Controversie sui titoli
- Problemi di licenza
- Scadenza del lease
- Complicazioni fiscali
